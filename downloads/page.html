Before you install

  • This is Early Access, not a stable release. Follow the supplied preflight and installation guide.
  • Ubuntu 22.04 and 24.04 amd64 are supported. ARM64 and a conflicting web or database stack are not.
  • There is no public stable APT repository or automatic update support in this distribution.
  • You operate the server and remain responsible for security, updates, backups, and recovery. No managed service or SLA is included.
  • The package, CLI, services, and installed paths retain the hipanel compatibility names.
  • Snotic Site Exporter is GPL-2.0-or-later. Its PHP fallback requires a quiesced source; it does not claim live-write consistency.

Final-byte integration tests used systemd-enabled LXD system containers on Ubuntu 22.04 and 24.04 amd64, not VMs. They do not establish the condition of your server.
