# Snotic Documentation

Snotic is a WordPress server-management platform developed and operated by
Pleesh.

## Current documentation

[Snotic Self-Hosted 0.1.30~rc1](self-hosted/0.1.30-rc1/index.md) is the current
Early Access documentation set. It covers an approved recipient operating the
supplied binary distribution on one customer-controlled Ubuntu server.

This documentation does not make the core application publicly downloadable or
open source. Distribution rights and limitations are defined by the supplied
[Early Access use terms](self-hosted/0.1.30-rc1/use-terms.md).

## Product names

- **Snotic** is the product.
- **Snotic Self-Hosted** is customer-operated software.
- **Snotic Managed** is a separate Pleesh-operated offering and is not covered
  by the Self-Hosted quickstart.
- **Snotic Site Exporter** is the WordPress migration plugin.

The current package, command, services, and installed paths retain the legacy
`hipanel` identifiers for compatibility. The versioned documentation uses
those exact identifiers wherever a command or machine path requires them.
